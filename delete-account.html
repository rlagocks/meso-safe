메소 금고 가계부 계정 삭제

계정을 삭제하면 아이디, 모든 수입·지출·메이플포인트 기록, 목표, 보스 빠른 입력 목록가 서버에서 완전히 지워지며 되돌릴 수 없습니다. 따로 보관하는 데이터는 없습니다.

앱에서 바로 삭제하기

  1. 메소 금고 가계부를 열고 로그인합니다.
  2. 맨 아래 계정 칸에서 계정 삭제를 누릅니다.
  3. 정말 삭제할게요를 한 번 더 누르면 바로 지워집니다.

"다시 로그인해 주세요"라는 안내가 나오면 로그인한 뒤 한 번 더 누르세요.

앱을 쓸 수 없을 때

비밀번호를 잊어서 로그인할 수 없다면, 가계부 링크를 알려 준 운영자에게 직접 아이디를 알려 주세요. 운영자가 확인한 뒤 계정과 기록을 지웁니다. 운영자를 모른다면 GitHub 문의 게시판에 "계정 삭제 요청"이라고 남겨 주세요 (아이디는 게시판에 적지 마세요).
